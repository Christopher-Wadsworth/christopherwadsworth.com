Assignment Description

This assignment is designed for learning to use the entire TLC cycle to learn a new thing. For the assignment, I chose to start learning Javascript (JS); the product I made can be seen by clicking right here.

Awareness

How did you become aware of a need that you wanted to meet?

I discovered the need throughout the semester when making this website. I can only do so much with the HTML and CSS, so to take some things to the next level in the future, I started learning Javascript.

How did you become aware that technology could be used to meet that need?

I became aware of it because JS is one of the three coding languages in website making, and it is the only one that can do some of the parts.

Exploration and Filtration

What process did you use to explore the variety of technology tools able to meet your need?

There was only one tool that could fit the needs that I had (putting the code into a website), so I chose that tool.

What process did you use [to] filter out a choice of tool from the many available?

I originally looked through many different possible starting codes on Google, looking for the one that was the most basic for me to be able to learn and adapt to.

Why did you choose to use the tool you selected?

I chose the one from "Geeks for Geeks" because of how clean the code was, making it easy to understand and modify as a beginner.

Learning

What process did you use to learn the tool?

I used a few different websites to give me the basics of the code linked here and here. I took the basic code from these pages and made many modifications and personalizations to it in an attempt to learn the basics. (The original code of the game can be played here.) Then whenever I ran into an issue, I would look it up on Google and find the answer in online message boards or Google's AI response.

What resources did you use or consult?

As previously mentioned, I used the Geeks for Geeks website as well as many online message boards and sometimes AI when bugs were too niche.

What was "missing" from the process or resources that might have helped you learn better or more quickly?

The thing that was really missing was a step-by-step guide for learning. Because I was just going from what I could see and understand, there were many basic things that I could have grasped sooner by consulting a basic guide.

Did you ever consider going back to the Filtration process to select another tool?

There were a few points where I thought about restarting with a guide. However, knowing that I find guides to sometimes be monotonous and boring kept me on the track I was going.

Professional and Personal Application

Once you learned the tool, how did you apply it in your professional life (that is, in what specific ways is the tool useful to you as a teacher)?

By learning JS, I can now create custom things for the classroom. I can curate online materials and games for the students to use that are perfectly connected to the lesson with ease.

Using a tool is great in your professional life, but finding a tool that works in your personal life is also important! How did/could you use the tool in your personal life?

In my personal life, I can now create the basics of a game, which sounds extremely enticing to me.

Sharing and Reflection

What makes this tool something you would share with other teachers? What "cautions" might accompany your recommendation? How did you share what you learned with someone else, either a product, knowledge, or both?

If teachers want to learn a tool for creating completely custom games and resources for their class, then this is perfect for that.

What is the tool missing? What do you wish the tool could do but either doesn't or is outside your capacity to learn?

Currently it is missing a general guide for anyone wanting to learn at any level. If I want to improve my skills, it will take a lot of work because there is no easy official place to get questions answered.

How did the TLC aid in your learning this time?

In all reality, it did not assist me in learning at all. When I started this project, I didn't completely read the description, and as I saw, "Learn something new!" My mind immediately went to this, which I've been looking to learn since we started on our WOW sites. I used the process, but I wasn't thinking about it at all; it's just the general process I take for learning new things.

How might you approach the TLC process differently the next time?

Next time I will probably actually use the TLC process intentionally, as that will make some of the steps easier.
